## Impeccable verification scope

This project supports desktop web only. For impeccable design, polish, harden, colorize, and review tasks:

- Do not create, adapt, inspect, screenshot, or test mobile or tablet layouts unless the user explicitly requests them.
- Verify desktop layouts and interactions only; use 1440×1000 as the default review viewport.
- This project-specific instruction overrides generic impeccable mobile/responsive verification guidance and older mobile requirements in surface briefs.
- Existing responsive implementation may remain; desktop-only support does not authorize deleting UI behavior or changing layouts outside the requested scope.
